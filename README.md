# Reminder / Daymark - Official OTA Updates & Release Channel

Welcome to the official updates and distribution repository for **Reminder / Daymark** (يومي).

## 🚀 Overview
This repository serves strictly as the release distribution channel:
- **`update_manifest.json`**: Real-time update registry checked automatically by client applications.
- **Delta Patches (`*.patch`)**: Ultra-lightweight BSDIFF40 delta packages (saves ~95% mobile bandwidth).
- **Official Releases**: Hosted on GitHub Releases with verified SHA-256 checksums.
